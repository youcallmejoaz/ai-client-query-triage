## The onboarding plan

New Growth and Enterprise clients get three onboarding calls: a kick-off,
a data import review and a parallel-run review. Calls are booked with the
onboarding team at https://tidewater.example/book-onboarding.

## Parallel run

We recommend running one payroll in parallel with your old provider before
going live, and comparing the results line by line.

## Go-live checklist

Import employees, confirm tax codes, add bank details for the funding
account, set up the direct debit mandate, and approve a test run at least 5
working days before your first live payday.
